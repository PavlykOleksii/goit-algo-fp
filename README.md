# Фінальний проєкт з алгоритмів та структур даних

- `Task_1.py` — однозв'язний список: реверсування, сортування вставками, об'єднання двох відсортованих списків.
- `Task_2.py` — фрактальне дерево Піфагора з використанням рекурсії, рівень рекурсії задає користувач.
- `Task_3.py` — алгоритм Дейкстри з використанням бінарної купи (`heapq`).
- `Task_4.py` — візуалізація бінарної купи.
- `Task_5.py` — візуалізація обходу дерева в глибину (DFS, стек) та в ширину (BFS, черга).
- `Task_6.py` — вибір їжі в межах бюджету: жадібний алгоритм та динамічне програмування.
- `Task_7.py` — моделювання кидання двох кубиків методом Монте-Карло.

## Завдання 7. Висновки

Було змодельовано 100 000 кидків двох кубиків. Для кожної суми від 2 до 12 підраховано кількість випадінь і обчислено ймовірність.

| Сума | Монте-Карло | Аналітично |
|------|-------------|------------|
| 2    | 2.67%       | 2.78%      |
| 3    | 5.68%       | 5.56%      |
| 4    | 8.14%       | 8.33%      |
| 5    | 11.10%      | 11.11%     |
| 6    | 14.13%      | 13.89%     |
| 7    | 16.54%      | 16.67%     |
| 8    | 13.92%      | 13.89%     |
| 9    | 11.12%      | 11.11%     |
| 10   | 8.27%       | 8.33%      |
| 11   | 5.68%       | 5.56%      |
| 12   | 2.76%       | 2.78%      |

Результати методу Монте-Карло дуже близькі до аналітичних. Найбільша різниця становить приблизно 0.24%.

Найчастіше випадає сума 7, тому що її можна отримати найбільшою кількістю комбінацій (6 з 36). Найрідше випадають суми 2 і 12, бо для кожної з них є лише одна комбінація.

Невеликі відхилення пов'язані з випадковістю. При кожному запуску результати трохи відрізняються, а зі збільшенням кількості кидків вони наближаються до аналітичних значень.

Отже, метод Монте-Карло дає правильні результати і підходить для оцінки ймовірностей.
